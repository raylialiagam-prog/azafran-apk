# AZAFRAN — Aplicación Móvil Android Oficial

Repositorio oficial de distribución de la aplicación móvil **AZAFRAN** para dispositivos Android (Huancayo, Junín, Perú).

## 📥 Descarga del APK Oficial
Puedes descargar el instalador oficial de producción directamente desde la sección de **[Releases](https://github.com/raylialiagam-prog/azafran-apk/releases/latest)**.

### Características del Release
- **Versión:** 1.0.0 (Build 1)
- **Firma digital:** Verificada mediante Android APK Signature Scheme v2 con certificado oficial de producción.
- **Compatibilidad:** Android 5.0 (API 21) en adelante.
- **Conectividad:** 100% independiente. Opera en redes móviles 4G/5G y Wi-Fi sin depender de servidores locales.

### Instrucciones de Instalación
1. Descarga el archivo `app-release.apk` en tu celular Android.
2. Abre el archivo descargado desde la barra de notificaciones o tu gestor de archivos (*Descargas*).
3. Si Android muestra el aviso de seguridad de aplicaciones de fuentes externas, selecciona **Ajustes** y marca **Permitir desde esta fuente**.
4. Pulsa **Instalar** y luego **Abrir** para ingresar a la tienda AZAFRAN.
